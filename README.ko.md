# 1on1 Compass

팀 리더를 위한 1:1 면담 사전 설문과 면담 가이드 도구입니다. 구성원에게 개인 링크를 보내 면담 전에 회고 답변과 DISC 유형을 받고, 그 사람의 소통 방식에 맞춘 면담 가이드를 만들어 줍니다.

[English →](README.md)

## 기능

- **개인 설문 링크:** 구성원마다 128비트 무작위 토큰이 담긴 링크를 줍니다. 링크로는 본인 설문만 열리고, 다른 사람 정보나 리더 메모는 보이지 않습니다.
- **질문 편집:** 성과, 아쉬운 점, 협업, 성장, 지원 요청에 관한 기본 질문 8개가 들어 있습니다. 대시보드에서 고치거나 더하거나 뺄 수 있습니다.
- **DISC 자가진단:** 15문항 진단을 하거나 유형을 직접 고릅니다.
- **면담 가이드:** 답변과 DISC 유형에 맞춰 도입 멘트, 추가 질문, 코칭 질문, 주의할 점을 만듭니다. 브라우저 안의 규칙으로 만들기 때문에 답변을 AI 서비스로 보내지 않습니다.
- **면담 기록:** 메모, 실행 항목, 등급, 코멘트는 리더만 보고, 구성원 링크에는 나오지 않습니다.

## 데이터 보호

- **리더 비밀번호:** 서버에 솔트를 넣은 scrypt 해시로만 저장하고 서버에서 확인합니다. 브라우저로는 보내지 않습니다.
- **로그인:** 12시간짜리 서명된 세션을 줍니다. 비밀번호를 바꾸면 모든 세션이 로그아웃됩니다.
- **로그인 실패 제한:** 15분에 IP당 10번, 전체 100번까지입니다.
- **구성원 목록, 메모, 등급:** 로그인한 리더에게만 보냅니다.
- **구성원 링크:** 자기 답변만 읽고 제출할 수 있습니다. 면담이 시작되면 답변이 잠깁니다.
- **저장 방식:** 구성원 한 명씩 따로 저장해서, 저장이 서로 덮어쓰지 않습니다.

링크를 가진 사람은 누구나 그 구성원 설문을 열 수 있으니 링크는 개인적으로 전달하세요.

## 빠르게 써 보기 (로컬 데모)

```bash
npm install
npm run dev            # http://localhost:5177
```

서버와 DB가 없으면 **로컬 데모 모드**로 실행됩니다.
- 데이터는 그 브라우저에만 저장되고, 데모 비밀번호는 `1234`입니다.
- 예시 구성원이 들어 있습니다.
- 구성원 링크는 같은 브라우저에서만 열립니다.

실제 팀 운영에는 아래 배포 방법을 쓰세요.

## 직접 배포하기 (Vercel + Upstash Redis)

1. 이 저장소를 Fork한 뒤 [Vercel](https://vercel.com/new)에서 가져옵니다. 프레임워크는 Vite입니다.
2. Vercel 프로젝트에서 **Storage → Marketplace → Upstash Redis**를 연결합니다(무료 등급이면 충분합니다). 그러면 `KV_REST_API_URL`과 `KV_REST_API_TOKEN` 환경 변수가 자동으로 추가됩니다.
3. 환경 변수 **`LEADER_PIN`**에 첫 비밀번호를 넣습니다(8자 이상).
4. 다시 배포하고 로그인한 뒤 대시보드의 **비밀번호 변경**에서 비밀번호를 바꿉니다.

첫 로그인 뒤에는 비밀번호가 DB에 해시로 저장됩니다. `LEADER_PIN`은 저장된 비밀번호가 없을 때만 쓰이므로 이후에는 지워도 됩니다.

배포 한 개는 팀 하나, 리더 한 명용입니다. 팀마다 따로 배포하세요.

## 개발

```bash
npm run dev        # 화면만 실행 (로컬 데모 모드)
npx vercel dev     # 화면 + API, .env.local 사용 (.env.example 참고)
npm test           # 메모리 저장소로 API 테스트
npm run typecheck
npm run build
```
